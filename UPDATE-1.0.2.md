# Моя кухня — обновление 1.0.2

## Что изменено
- `app.js`: кнопка «Проверить обновления», статус, предложение установить загруженную версию, перезагрузка после подтверждения и смены Service Worker.
- `sw.js`: новый кеш `moya-kuhnya-v1.0.2-20261122`, загрузка свежих файлов из сети при установке, удаление только старых кешей `moya-kuhnya-*`; IndexedDB не затрагивается.
- `styles.css`: ненавязчивое уведомление о доступной версии.

## Установка через GitHub
1. В приложении: Настройки → Скачать базу (JSON). Сохрани файл **вне приложения**.
2. В репозитории `pryanyy-med/moya-kuhnya` замени файлы **app.js, sw.js, styles.css** на файлы из архива.
3. Дождись публикации GitHub Pages. На Android открой приложение при работающем интернете, затем полностью закрой и открой снова. Первое обновление с 1.0.1 до 1.0.2 активируется автоматически, поскольку в 1.0.1 ещё нет новой кнопки обновления.
4. После появления v1.0.2 открой Настройки → Проверить обновления. Проверка `registration.update()` появится в текущей и будущих версиях.

## Для разработчика следующей версии
**Важно:** В этой версии `sw.js` специально делает `skipWaiting()` при установке, чтобы преодолеть проблему начальной версии 1.0.1 (она кеширует старый `app.js` и не умеет предлагать обновления). При следующем выпуске 1.0.3 нужно удалить строку `await self.skipWaiting()` из `install`, увеличить `CACHE` и оставить переход через сообщение `SKIP_WAITING` (обработчик уже есть). Тогда появится уведомление о новой версии и пользователь подтвердит обновление кнопкой.

## Данные
Версия базы IndexedDB и логика импорта/экспорта не менялись. Приложение никогда не очищает IndexedDB при обновлении. Но резервную копию перед выпуском всё равно стоит делать.

## Проверка
- Редактирование рецепта → сохранение → проверка после обновления.
- Настройки → Проверить обновления с интернетом: сообщение об актуальной версии.
- При следующем выпуске 1.0.3: обновление скачивается, появляется уведомление и кнопка «Установить новую версию», подтверждение → новая версия.
- Офлайн: ранее посещённые страницы и данные рецептов доступны без сети.
