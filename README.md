# Моя кухня — мобильная книга рецептов (PWA)

Первая версия: каталог рецептов, редактирование, YouTube-ссылки, недельный план (несколько блюд на один приём пищи), расчёт КБЖУ, автоматический список покупок, локальная база IndexedDB, экспорт и импорт JSON, офлайн-кеширование.

## Установка на GitHub Pages

1. Создайте **публичный** репозиторий, например `moya-kuhnya`, на GitHub.
2. Загрузите **содержимое этой папки**, а не папку целиком: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest` и каталог `icons`.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Выберите ветку `main`, каталог `/ (root)` и нажмите Save.
4. GitHub покажет адрес вида `https://USERNAME.github.io/moya-kuhnya/` — откройте его в Chrome на Android.
5. В меню Chrome (⋮) выберите **Установить приложение** или **Добавить на главный экран**. Действие зависит от версии браузера.

Для работы PWA нужен HTTPS (GitHub Pages предоставляет его бесплатно). При первой загрузке необходим интернет. Потом каталог, меню и покупки могут работать офлайн. YouTube-видео требуют интернета.

## Как пользоваться

- **Рецепты:** можно открыть стартовые демо-рецепты, изменить/удалить их или создать собственные.
- **Ингредиенты:** по одной строке `Продукт | количество | единица`, например `Куриная грудка | 500 | г`. Указывайте количество на весь рецепт, а КБЖУ — **на одну порцию**.
- **Неделя:** нажмите `+` напротив приёма пищи и выберите рецепт. Можно добавлять несколько блюд в один приём. Нажмите на уже добавленное блюдо, чтобы изменить количество порций или удалить.
- **Покупки:** автоматически агрегируют ингредиенты блюд выбранной недели с учётом количества порций. Продукты совпадают только при одинаковых названиях и единицах; проверяйте граммовки.
- **КБЖУ:** вычисляется по введённым значениям на порцию. Стартовые показатели — **приблизительные примеры**, их нужно сверить с собственными рецептами.
- **Резервная копия:** ⚙ → «Скачать базу (JSON)». Храните этот файл отдельно от браузера. «Восстановить из JSON» заменяет текущие данные.

## Важно про данные

Данные сохраняются на телефоне в IndexedDB под адресом сайта. GitHub не получает введённые в приложении рецепты и меню. Однако **исходный код и стартовые демо-рецепты в публичном репозитории доступны всем**. Не загружайте в репозиторий личные резервные копии JSON.

Удаление данных сайта или браузера, смена адреса репозитория, сброс или потеря телефона могут привести к утрате локальной базы. Регулярно экспортируйте JSON. Не переименовывайте репозиторий после установки без переноса данных.

## Локальная проверка на компьютере

В папке с проектом выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`. На `localhost` service worker может работать без HTTPS. Открытие `index.html` напрямую через `file://` не поддерживается.

## Технические ограничения версии 1.0

- КБЖУ вводятся вручную, не рассчитываются по ингредиентам автоматически.
- Список покупок не вычитает запасы продуктов дома и не конвертирует единицы измерения.
- Синхронизации между устройствами нет.
- Фотографии не хранятся; используются значки блюд. YouTube-ссылки доступны.
- Тестировалось как статическое PWA; офлайн-кеширование после первого посещения может зависеть от настроек Android/Chrome.
